# 真机验收清单

> 当前状态：**未验证**。下列任一项完成后，请在 issue 里附设备与版本信息。

## 环境

| 项 | 值 |
|---|---|
| 头显 | Quest 2/3/Pro、Pico 4 Pro/Enterprise、Vive Focus 系列（记录型号） |
| ALVR 服务端版本 | 记录版本号（face.rs 前缀表随版本可能变化） |
| ALVR 客户端版本 | 与服务端同版本 |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |

## 步骤

- [ ] ALVR 服务端设置：Eye and face tracking 设为 VRCFaceTracking
- [ ] PC 上关闭 VRCFT 及其它占用 41463 的程序
- [ ] FGB「模块库 → 原生模块」安装 `alvr-<版本>.zip`
- [ ] 「模块」页把 ALVR 设为启动，重启引擎
- [ ] 佩戴头显开始串流，模块卡片显示活跃

## 观察项

- [ ] 张嘴 → `JawOpen`（Quest 走 `Face2Fb`、Pico 走 `FacePico`、Vive 走 `LipHtc`，三选一都要覆盖）
- [ ] 微笑 → 嘴角上扬 + CheekSquint 近似项
- [ ] 眨眼 → 睁眼度下降，左右眼独立（支持眼动的设备）
- [ ] 看左/右/上/下 → 注视方向不反向（`EyesQuat` 设备的极化重点确认）
- [ ] 说话（音频表情源）→ 唇部形状跟随
- [ ] 断开串流 → 10 秒内卡片给出「已 N 秒没有数据」
- [ ] 恢复串流后自动回到活跃

## 与上游对比（可选但有用）

同一台头显并用 VRCFT 的 ALVR 模块，对比同一组表情的参数曲线，
记录明显不一致的形状名。特别是：

- `FacePico`：确认你的 ALVR 版本实际发的是 52 还是 72 float
  （模块日志出现「尾部块不完整」即为 72 布局，需要回报版本号）；
- 注视极化（左右眼、yaw/pitch 符号）需要人眼确认。
